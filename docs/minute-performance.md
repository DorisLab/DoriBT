# 分钟场景：DoriBT 与 vectorbt 的首轮比较

日期：2026-10-06。引擎提交 `145944f`，DoriBT 0.2.0.dev0、vectorbt 0.28.5、NumPy 2.5.3、Numba 0.68.0、Python 3.13.12；Windows 11、Ryzen 7 9800X3D（8 核／16 线程）。[原始汇总 JSON](minute-performance-2026-10-06.json)保留样本、版本、输入和适配器哈希。

## 结论

**这个分钟场景中，vectorbt 明显更快。当前 DoriBT 的 Numba 后端没有带来整体性能的显著提升。** 相同单账户曲线和成交输出下，vectorbt 预热耗时约为 DoriBT Numba 的 1/38；十组参数约为 1/46。DoriBT 的进程内存较少，第一次调用的成本也较低；不能用早期原型结果宣称完整引擎比 vectorbt 更快。

## 对齐的工作量

输入为 159915.SZ、2025-03-21 至 2025-08-20 的 104 个交易日／24,960 根 1 分钟线。该连续区间的行情校验、时间映射与被排除的数据问题见[分钟验收](minute-validation.md)。

每天 09:45 用已完成 bar 的均线决定目标 10,000 份或零；快线依次 30、40、…、120，慢线 240。每组独立十万元，T+1、每个 DAY 子单万三佣金／最低五元、1 tick 不利滑点、0.1% 成交量参与率；日内延续部分成交，跨日按合法数量生成新子单。竞价只估值，未发生公司行动。

三种执行方式的十组逐 bar 现金、持仓、权益和逐笔成交都与同一独立 Decimal 参考一致；公开参考不导入引擎的账户、撮合或费用函数。DoriBT 按整数单位精确相等；vectorbt 浮点曲线按 1e-8 元容差核对，成交价格／金额／佣金规范化后精确相同。这里只比较这个有限模型，没有验证 vectorbt 的所有市场制度。

## 实测

预热单次和参数组取三次运行的中位数；每种执行方式独立新进程和空 JIT 缓存，复测期间没有同时运行本仓库质量门禁。

| 执行方式 | 首次执行（含新缓存 JIT） | 预热单账户 | 预热十组参数 | 整个 worker 峰值 RSS |
| --- | ---: | ---: | ---: | ---: |
| DoriBT Python | 1.157 s | 621.1 ms | 6.179 s | 112.8 MiB |
| DoriBT Numba | 3.675 s | 578.5 ms | 5.975 s | 217.9 MiB |
| vectorbt 0.28.5 | 11.168 s | 15.4 ms | 0.129 s | 557.5 MiB |

数据解析／共同准备另计，三者约 1.37–1.38 秒。首次执行不包含 import，不是进程完整冷启动。预热计时包含现金／持仓／权益曲线及成交表物化，排除输入解析、信号计算、独立对账与文件导出。

DoriBT 复用 Backtest 的行情缓存，串行调用十次；vectorbt 一次传入十列独立账户。DoriBT 同时产生订单、意图和运行来源等附加结果，vectorbt 适配器保留其内部状态与成交表；没有剥离这些额外成本，也不能把这种结果范围差异隐藏为撮合内核的纯速度差。

RSS 每 5ms 采样整个进程树，包含载入、依赖、JIT、参数结果保留及验证阶段，不能视为单个账户或内核的独占内存。初次并行跑门禁的试测只用于验证工具，本表使用随后单独运行的复测。

## 瓶颈与下一步

预热 Numba 的 cProfile 定位显示，约 343 万次 Python 调用仍留在整轮流程中：24,960 次 `_close` 累计约 0.546 秒、`_context` 约 0.362 秒、`_open` 约 0.326 秒；账户数量聚合约十万次、NumPy 小数组构造约十五万次。Profiler 本身有开销，这些秒数仅用于定位，不能代替上表计时。

目前 Numba 编译的是成交计算，逐 bar 的账户状态、目标维护、估值和 Context 构造仍由 Python 调度。下一轮应优先为预计算目标提供整段数组状态循环，将账户数量／可卖量保持在数组中，并按需物化对象结果；任意 Python 策略回调保留灵活入口。公司行动、交易日解锁与同一订单累计费用仍须进入等价验证，不能通过减少规则或结果来制造提速。

当前仅完成单标的、十参数首轮比较。多标的共享账户、更多参数、活跃日内回调、长样本和分配事件场景尚未比较。完整复跑方法及独立 vectorbt 适配器见[比较协议](../benchmarks/minute/README.md)。

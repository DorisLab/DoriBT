## 执行节奏

每个主要目标完成后本地完整检查并提交。普通 push／PR 不触发 CI；里程碑使用 `milestone/<name>` 标签，发布候选／正式版本使用 `v*` 标签运行跨平台检查。仅在明确的里程碑验收时手动运行 workflow。每次里程碑继续审视 API 的自然程度、状态与失败语义，不能用累积兼容包装代替设计改进。

首次发布默认交付 GitHub Release 的源码、wheel、sdist、校验和与发布说明。PyPI 分发需另有可用的发布身份和配置；不能把未上传 PyPI 说成已上传。任何外部阻碍不影响可独立推进的引擎工作。

下一主要目标：建立正式多标的数据与规则入口，为共享账户和事件策略提供准确输入。

# 当前共享账户执行契约

状态：多标的账户、收盘策略、目标权重及开盘执行已实现；公司行动和股息税尚未实现，含行动的数据明确拒绝运行。这是基础引擎的一部分，不是首版已完成声明。

## 研究入口

`Backtest(data, initial_cash=..., costs=Costs(...)).run(strategy, backend="python")` 接受收盘函数，也接受 `WeightTargets`。策略函数获得 `Context`，无需继承类；策略参数可以由普通函数工厂或可调用对象持有。每次 `run` 都建立独立账户，但有自身状态的策略对象须由用户为各次运行重新创建。

- `ctx.history(symbol, bars=..., field="close")` 返回截至当前收盘的只读价格副本，支持原始 OHLC；当前窗口不足时返回已有历史。此接口防止无意读取未来数据，不是对恶意 Python 代码的沙箱。
- `ctx.account` 提供元为单位的现金、权益及按证券查询的不可变持仓／可卖量；`ctx.orders`、`ctx.intents` 提供截至当前的记录。
- `ctx.order(symbol, quantity)` 提交有符号股数，仅尝试下一输入交易日；负数卖出。数量不合法会留下拒绝记录，不默默凑整。
- `ctx.target_positions({symbol: quantity})` 持续尝试达到绝对股数，省略证券保持原目标。新目标替换同证券旧目标，记录取消原因。
- `ctx.target_weights(weights, rebalance=False)` 设置整个组合的目标权重，省略证券为零。权重变化时按当前收盘权益和价格确定股数，按当期规则向合法数量取整；相同权重继续原股数目标，不每天再平衡。显式 `rebalance=True` 每次重算。
- `ctx.cancel(intent_id)` 取消仍活动的意图。回调结束后不能再通过保存的 Context 改订单。

预计算 `WeightTargets` 日期必须与行情逐项一致，权重非负、总和不超过一。它调用同一收盘入口，默认同样只在权重变化时重算。输入被保存为不可变值；不自动丢行、重排或前填。自动延迟执行不能证明用户因子没有前视。

## 每日顺序与共同现金

先解锁到期批次，再生成上一收盘意图的当日委托，以当日开盘和配置滑点执行；先卖后买，同侧按 `MarketData.symbols` 的声明顺序处理。卖出所得立即可用于后续买入。每个证券同一时点只有一个活动意图，多次提交会按替换规则留痕。

权重委托的股数在收盘确定。下一开盘跳空不重新按开盘权益配比，资金不足时减至能支付费用的合法股数；原目标保留未完成部分，下日重试。单次股数委托的剩余量当日到期，不自动重试。原 `experimental` 预算模型继续单独保留，不冒充固定股数模型。

买入批次按买入日规则确定交收交易日，周末不当作一个交易日。卖出只消耗已解锁 FIFO 批次。当前模拟没有盘中回调，即使数据声明 T+0，也不因此产生当天收盘下单、当天开盘卖出的穿越行为。

## 委托、成交与费用

`result.intents` 是目标和有效期，`result.orders` 是当日尝试，`result.fills` 是实际成交，分别带 ID 并可追溯关联。委托事件包括创建、接受、成交／部分成交、拒绝／到期；部分成交后剩余部分当日到期。替换和用户撤销记录在持续意图上。样本结束仍未执行的意图标记 `end_of_data`，不暗中强平。

日线模型每个证券每日只模拟一个成交片段，因此最低佣金按该日委托收取一次，分项记录佣金、印花税和过户费；不是每笔内部资金试算都收费。费用按分半入，账本使用整数万分之一元，金额溢出直接失败。佣金是否包含其他券商规费由用户配置决定，当前仅显式另计印花税和过户费。

现金在顺序撮合过程中立即占用并记账，未成交委托当日到期；收盘视图的冻结现金为零，没有跨日冻结订单。当前未提供取款接口或银行结算模拟，不能把收盘现金解释为已核验的可提现额度。

## 日线成交假设

停牌、未上市／已退市、零成交量、买入开盘触及涨停、卖出开盘触及跌停均不成交并记录原因。价差滑点按证券 tick 计，超过已知日价格边界时不成交。不使用当天最终最高／最低价裁剪开盘价格，不读取当日收盘价反算开盘数量。

零成交量阻止成交属于整根日线的历史模拟约束。当前不按日成交量比例设置数量上限，也不模拟盘口排队或集合竞价撮合；有成交量不意味着真实市场可以无冲击执行任意数量。库存按收盘原始价估值，持仓进入无估值的退市状态直接失败，不能以零价格清空。

## 后端及结果边界

Numba 加速同一个整数开盘执行循环；生命周期、批次和任意 Python 策略回调仍在 Python 层。预计算目标也走此流程，当前不承诺整个账户按一次 JIT 批量编译，更不能引用原单标的原型的速度作为本引擎成绩。

结果包含一维权益／现金、按证券命名的持仓／可卖量矩阵、全部意图／委托／成交、数据指纹和实际后端。整数单位字段用于精确复核；元为单位的属性用于研究。收益从本次初始现金算起，回撤峰值包含初始现金。完整风险指标、基准、图表、导出和策略来源记录仍待后续结果目标。

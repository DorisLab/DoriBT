# 设计方向与路线图

状态：方案，尚未实现的内容不构成支持承诺；没有固定完成日期。

DoriBT 面向日线低频研究。计划采用 Python 输入／规则层和 Numba 状态内核，保持规则、模拟假设、策略意图三者独立：

- 市场规则：历史板块、交易单位、T+1、停复牌、有效日期和来源。
- 执行模型：开盘代理成交、滑点、方向性价格限制与资金分配顺序。
- 策略：信号、目标仓位与撤销／替代目标，不能直接写账户账本。

## 状态和数值原则

账户区分可用、冻结、未交收资金和应收权益；持仓区分总量、可卖量、冻结量与批次。意图可跨日，委托有有效期；市场暂时无法成交与输入非法使用不同原因。完整引擎中，每笔成交必须能追溯唯一委托及规则版本。

规则按证券属性和历史有效日期匹配，重叠或缺失即失败；不使用当前 ST 状态反推历史。开盘成交只使用该时点可知信息；收盘价用于估值和后续决策。日线政策不能声称精确模拟盘口排队。

原始价格用于记账，公司行动用于调整权益，研究价格另行处理。公司行动需考虑登记日、除权日、到账日和可卖日，避免同时使用复权价成交并重复增加股息。遇到尚未支持的持仓事件必须明确失败。

金额采用可核对的固定精度整数，费率和舍入点明确；实际使用的代码、依赖、数据、规则及执行假设都需要进入结果来源记录。历史结果保持其原始版本，失败不能覆盖之前的成功结果。

## 首版不覆盖

实盘执行、分钟／逐笔撮合、盘口排队、融资融券、期货期权、ETF 申赎和通用跨市场交易系统不属于首版目标。适配器也不自动意味着第三方平台任意代码可以无损运行。

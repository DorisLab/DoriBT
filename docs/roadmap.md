# 开发目标

本文描述交付目标，不按内部实验或编码切片排列公开版本。第一项已于 2026-10-06 以 [0.1.0](https://github.com/DorisLab/DoriBT/releases/tag/v0.1.0) 发布，逐项证据见[首版验收](release-0.1.0.md)；当前可用能力见 [README](../README.md)与[执行模型](execution-model.md)。后续路线和时间依据实际研究需求决定。

## 第一项交付：基本完整的日线回测引擎

用户能够用自己的数据编写单标的或组合策略，完成运行、解释成交与收益、比较结果和复现研究。范围为人民币现金账户、做多、日线沪深股票和境内股票 ETF；具体证券类别、历史区间和特殊状态以随版本发布的支持矩阵为准。

数据、策略、订单、账户、规则、分析和交付体验须一起达到基本可用。只有高速计算循环或单一均线样例，不能算这一目标完成。

| 能力 | 基础交付要求 | 可观察的验收 |
| --- | --- | --- |
| 数据与时间 | 本地表格数据入口，交易日历、证券标识、历史状态、原始价与研究价格的区分；日期和数据缺口诊断 | 用户数据完成一次回测；缺价、错位、重复日期及未知状态有明确错误；未来数据不改变历史决策 |
| 策略编写 | 收盘事件策略与预计算信号／目标两种入口；参数、历史窗口、持仓／订单查询、股数与目标权重意图 | 买入持有、均线择时、多标的轮动均可用公共 API 编写，无须修改内核；时间语义一致 |
| 执行与订单 | 明确的次日开盘模型，意图／委托／成交分离、撤销／到期／拒绝原因、费用与滑点；目标替代和不足额处理 | 跳空、停牌、价格边界、现金不足、目标变化均有可追踪结果；固定股数与预算型下单明确区分 |
| 账户与组合 | 多标的共享资金、确定的卖出／买入顺序、可用／冻结资金、持仓批次与可卖量；独立回测账户隔离 | 逐笔成交可重建现金和持仓；无隐含负现金或卖空；不能把参数账户误当多资产组合 |
| A 股规则与权益 | 带来源及有效日期的数量、价位、T+1、停复牌、价格限制和税费；支持范围内的现金分红、送转及相关税务 | 交易日解锁、规则切换、零股与公司行动前后账目可核对；未覆盖事件显式失败，不用默认值蒙混 |
| 结果分析 | 净值、现金、持仓、订单／成交与费用表；收益、回撤、风险指标及基准；基础图表和标准格式导出 | 用户能定位某次未成交及其影响；指标有清晰口径，导出结果可独立对账和用于报告 |
| 可复现与交付 | 记录数据、策略参数、规则、执行假设及依赖版本；可安装包、示例、API 文档、两种后端 | 干净环境能按文档运行并重现结果；Windows／Linux、Python／Numba 与独立账本验证通过 |

首个版本发布前，用以上三类策略串起完整流程，补充包含规则变更和公司行动的有来源案例。真实行情只在授权允许的环境中验证；公开仓库保留可公开的最小复现和独立预期。Python／Numba 执行同一循环的结果一致，不能代替独立账本和市场案例。

## 参考项目带来的设计取舍

参考公开接口与职责划分，具体能力仍按 DoriBT 的市场范围实现：

- [Backtesting.py](https://kernc.github.io/backtesting.py/doc/backtesting/backtesting.html)：研究流程围绕 `Backtest`、策略、运行结果展开，策略可以获得随时间推进的数据视图。借鉴清楚的使用路径和数据可见性。
- [bt](https://pmorissette.github.io/bt/)：可组合策略和组合回测值得借鉴。组合调仓应成为用户直接使用的能力，而非让用户拼账本循环。
- [vectorbt](https://vectorbt.dev/api/portfolio/base/)：区分信号、订单及更底层回调的入口，方便批量研究。DoriBT 将参数批量作为显式研究能力，保持参数账户与共享资金组合的区别。
- [RQAlpha](https://rqalpha.readthedocs.io/zh-cn/latest/intro/overview.html)：策略运行、账户结果与分析的完整流程值得参考。数据、市场规则和执行模型应有明确扩展边界。

这些项目不会成为 DoriBT 必须依赖的运行框架，也不据此宣称接口兼容。API 的当前实现与目标职责见 [API 设计](api-design.md)。

## 基础引擎完成后的候选方向

以下是候选能力，尚不指定版本、顺序或日期：

- 参数批量、优化、样本外与滚动验证，提供可解释的结果比较和资源消耗报告。
- 根据实际数据和性能需求扩展更细周期或更多证券类型，同时补齐相应执行模型与验证。
- 第三方量化平台策略适配器，逐项列明支持的 API、生命周期和语义差异，并用可复现策略验证。
- 更丰富的分析图表、报告和数据源适配，保持引擎可独立使用。

## 持续遵守的边界

市场制度、历史市场状态和回测假设分别表达；原始价用于记账，研究价格与公司行动不会重复计入权益。账户金额使用可核对的固定精度，指标浮点数不反向修补账本。失败不能覆盖已有成功结果，未知规则不能静默退回当前规则。

实盘执行、盘口排队、融资融券、期货期权及 ETF 申赎不属于这次基础引擎目标。日线模拟不宣称精确还原盘口成交，也不保证第三方平台代码可无损转换。

# 开发方向

DoriBT 专注 A 股与 ETF 的轻量高性能回测：历史交易规则开箱即用，普通 Python 函数表达策略，Numba 加速回放，完整账户与交易记录用于分析和导出。

当前支持日线及 1／5 分钟、部分成交和滑点、分红送转、参数声明、日频报告与自定义研究输出。范围以[市场规则](china-market.md)及[接口参考](api.md)为准。

后续围绕实际研究需求推进：

- 参数组合比较、样本外与滚动验证。
- 更密集成交和多证券负载下的性能优化，保留完整可对账结果。
- 第三方量化平台代码适配，明确支持的生命周期、API 与语义差异。
- 数据源适配、报告和可视化，保持引擎可独立安装使用。

欢迎通过 [Issues](https://github.com/DorisLab/DoriBT/issues) 提供研究任务、预期行为和最小案例，帮助下一步开发聚焦实际需求。

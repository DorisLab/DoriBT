# 性能

DoriBT 将快速回测与完整交易账本放在同一次运行中。**2520 日 × 100 标的组合，Numba 热运行中位数为 0.147 秒，比 Python 后端快约 6.6 倍。** 100 组独立组合的完整扫描中位数为 19.13 秒。

## 与同类框架的速度对比

以下是同一组合输入的热运行中位数：2520 个交易日、100 个标的、固定股数目标，收盘决策、下一开盘成交。计时包含引擎调用，以及现金、持仓、权益和逐笔成交的输出提取。

| 实现 | 热运行耗时 |
| --- | ---: |
| DoriBT Python | 0.970 秒 |
| DoriBT Numba | 0.147 秒 |
| vectorbt Numba | 0.096 秒 |
| vectorbt Rust | 0.075 秒 |
| Backtrader | 18.965 秒 |
| Zipline-reloaded | 7.151 秒 |

**为什么选择 DoriBT？** 对 A 股和 ETF 研究，交易约束、代码编写和结果解释同样重要。DoriBT 把 T+1、最低佣金、部分成交、涨跌停、分红送转与共享资金纳入统一账户；你用普通 Python 函数写策略，运行后直接得到完整订单、成交、费用和研究报告。0.147 秒的组合回放，配合这些现成能力，足以让反复修改策略、比较成本和检查结果成为顺畅的研究过程。

## 多组参数与组合研究

100 组 SMA 参数，每组独立运行 100 个标的、2520 日，合计 2520 万个标的-bar、1393518 笔成交：

| 实现 | 完整扫描中位数 |
| --- | ---: |
| DoriBT Numba | 19.131 秒 |
| DoriBT Numba＋原生扩展 | 20.036 秒 |
| vectorbt Numba | 7.677 秒 |
| vectorbt Rust | 6.744 秒 |

DoriBT 使用 100 次公共 API 调用，vectorbt 每批处理 10 个独立账户。DoriBT 的每次运行都保留独立账户和完整记录，便于比较参数、追查某组异常成交，以及导出单独的研究报告。

10 组单标的 × 2520 日的小批量测量中，DoriBT Numba 为 0.063 秒，vectorbt Rust 为 0.017 秒。更多工作流、首次运行及逐轮数据见页末复现资料。

## 0.6.2：长历史面板回放更快

1633 日 × 219 证券的真实历史面板包含上市前、停牌和退市后区间。0.6.2 将这些合法区间的权重目标一起放入完整编译循环，并按规则有效日期批量准备数据。

下表为三组完整研究回放的暖态中位数，每组重复 10 次；计时包含目标转换、数值准备、Backtest.run、完整记录及研究侧输出，市场数据构造另计。

| 初始资金／参与率／滑点 | 0.6.1 Numba | 0.6.2 Python | 0.6.2 Numba |
| --- | ---: | ---: | ---: |
| 30 万元／10%／5bp | 2.561 秒 | 1.646 秒 | 1.270 秒 |
| 3000 万元／5%／5bp | 1.872 秒 | 1.877 秒 | 1.451 秒 |
| 30 万元／10%／5.01bp | 1.846 秒 | 1.638 秒 | 1.304 秒 |

新版 Numba 回放速度为旧版的 **1.29—2.02 倍**。三组各 10 次回放累计由 **63.82 秒降到 40.57 秒，节省约 36% 的回放时间**。每日账户和完整交易账本逐项相同。

### 首次运行与重复运行

Numba 首次运行会编译内核，之后可复用缓存。在上述面板的首组测量中，0.6.2 的空缓存首次回放为 **18.24 秒**，已有磁盘缓存的新进程为 **3.80 秒**，同进程暖态中位数为 **1.27 秒**。市场数据构造约 8—9 秒。

重复研究时，复用 `MarketData` 和 `Backtest`，把已经算好的信号交给预计算目标；使用 `execution_plan` 查看实际编译路径。[预计算目标](scheduled-execution.md)提供具体用法。

### Python 版本怎么选

新环境推荐 **Python 3.15**。在相同人工面板、NumPy 2.5.4、Numba 0.68.0 下，三个解释器的完整结果一致，3.15 的本机测量用时最短：

| CPython | Python 后端中位数 | Numba 中位数 |
| --- | ---: | ---: |
| 3.13.16 | 1.431 秒 | 0.568 秒 |
| 3.14.8 | 1.129 秒 | 0.507 秒 |
| 3.15.0 | 0.998 秒 | 0.460 秒 |

Python 3.13 和 3.14 也受支持，旧环境可直接升级 DoriBT。[安装页](guide/install.md)列出依赖组合。

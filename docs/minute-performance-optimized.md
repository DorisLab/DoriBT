# 分钟预计算策略：优化后与 vectorbt 比较

日期：2026-10-06。DoriBT 0.2.0.dev0（未发布）、vectorbt 0.28.5、NumPy 2.5.3、Numba 0.68.0、Python 3.13.12。Windows 11、Ryzen 7 9800X3D，8 核／16 线程。[原始汇总](minute-performance-optimized-2026-10-06.json)记录所有计时样本、输入哈希及引擎／适配器文件哈希，用来识别实际测量代码。

## 工作量

159915.SZ，2025-03-21 至 2025-12-31，193 个完整交易日、46,320 根 1 分钟线。原始首日 2025-03-20 只有半日输入，仍不伪造补齐；每天排除额外的 09:30 行，14:58–15:00 只估值。2025-08-21 的分钟／日线成交量差异保留为来源信息，**没有因该差异剔除日期或修补分钟成交量**。所有路径读取同一份分钟数据。

初始十万元、每日 09:45 的分钟 SMA 决策、快线 30／40／…／120、慢线 240、目标 10,000 份或空仓。T+1、每 DAY 子单最低五元且万三佣金、1 tick 不利滑点、0.1% 成交量参与率；未完成目标跨日续单、竞价不撮合、不强制清仓。样本内没有公司行动，不能将此性能排名推广到分配事件密集的组合。

与[首轮比较](minute-performance.md)相比，数据长度已经变化，所以本轮重新测量原逐 bar 回调作为同口径对照，不直接用上轮秒数计算提速。

## 测量结果

预计算 Numba 路径相对本轮逐 bar Numba 路径，单账户约快 **15.0 倍**，十参数约快 **16.7 倍**。vectorbt 仍然更快：其单账户耗时约为 DoriBT 优化路径的 1/2.2，十参数约为 1/2.5；不能宣称 DoriBT 已超过 vectorbt。

每种路径独立进程、空 JIT 缓存；单账户与十参数均取三次预热运行中位数。复测不与本仓库门禁同时运行。原始样本全部保留，不用最快一次代表结果；十参数计时是独立测量，不能直接按单账户中位数乘十。

输入准备约 2.56／2.56／4.16／3.76／2.69 秒（顺序同表），预计算路径多出十个不可变目标对象的验证／构造。Numba 分段路径增加了编译和缓存成本，首次调用比 DoriBT 原回调更慢；本轮加速主要惠及同一数据上重复研究与参数比较，基础 Python 预计算路径也有明显收益。

## 实现与验证口径

[分段执行](scheduled-execution.md)按目标变化、可能成交、市场状态变化和交易日首尾推进；稳定区间由 Numba 扫描、NumPy 批量估值。实际委托、成交、共享现金、交收、权益和结果仍使用正式生命周期。这次没有实现完整账本 JIT 或任意 Python 回调编译，也没有削减 DoriBT 的结果记录。

来源 JSON 缓存不可变行情与预计算目标，仍逐次读取源码哈希、参数和依赖版本。当前版本的旧回调与预计算路径都享受行情／来源缓存；回调每 bar 被调用，但只在目标变化时重新声明，使用相同目标数组。

十组参数的每分钟现金、持仓、权益和逐笔成交均与独立 Decimal 参考核对。DoriBT 按整数记账单位精确相等；vectorbt 的浮点曲线容差为 1e-8 元，成交数量、价格和费用规范化后精确相同。模拟规则见[比较协议](../benchmarks/minute/README.md)，此适配器没有验证 vectorbt 的全部 A 股语义。

预热计时包含 Backtest.run、完整结果生成、运行来源和共同曲线／成交表物化；输入解析、信号计算、PositionTargets 对象构造、独立对账和文件导出另计。首次执行包括行情准备和空缓存编译，排除 import／输入解析，不是进程完整冷启动。

DoriBT 串行运行十个独立账户，vectorbt 一次传入十列；DoriBT 额外产出订单、意图、冻结、权益和来源记录，vectorbt 适配器保留其账户状态和成交表。此差异未从 DoriBT 计时中剥离，不能将总时间当作纯撮合内核速度。

RSS 每 5ms 采样进程树，覆盖载入、依赖、编译、参数结果保留和验证；不代表单次回测独占内存。公开文件只有脚本、输入哈希和汇总，不包含真实行情。

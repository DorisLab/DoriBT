# 股票权益与税务批次

本页定义现金分红、送转入账／解锁及普通个人税务批次的依据、范围与账本口径。

## 已核验的依据

- [财税〔2015〕101 号](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)：公开市场取得的普通流通股，个人股息税按持有期适用 20%、10% 或超过一年暂免；分配时不预扣，转让后结算。
- [财税〔2012〕85 号](https://www.chinatax.gov.cn/chinatax/n810341/n810765/n812151/n812386/c1082457/content.html)及[中国结算操作问答（证监局转载）](https://www.csrc.gov.cn/shenzhen/c105614/c1575308/content.shtml)：采用 FIFO 和账户日终净增减股份，持有期按自然月／年计算，不是固定 30／365 天。问答旧税率已被 2015 年政策更新，本实现只沿用操作口径。
- [资本公积与红股税务说明](https://tianjin.chinatax.gov.cn/nsrxt/11200000000/0500/050017/20180720150119487.shtml)：股票溢价形成的资本公积转增与应税红股不能混为一类，需要公告提供送转的应税金额。
- [基金分配税收说明](https://shanghai.chinatax.gov.cn/xwdt/ztzl/zcgll/jsjf/rdwd/202507/W020250701564131535886.pdf)：普通个人从开放式证券投资基金分配中取得的收入暂不另征个人所得税；不能把基金内部的股票税再扣一次。
- [发行人送转公告示例](https://disc.static.szse.cn/disc/disk03/finalpage/2022-06-02/b634197f-aefd-410a-b0e9-936c060e09e7.PDF)：零碎股份实际分配可能涉及全体股东排序与随机分配，单个模拟账户不能据此假装还原真实零碎股分配。

以上政策实现仅适用于境内普通个人持有的沪深公开市场流通股及境内股票 ETF，不覆盖机构、境外投资者、限售股及退市板块。其他身份不得套用此模型。交易制度及历史费用须同时满足[市场支持矩阵](china-market.md)。

税务版本为 `cn-individual-2015@2026-10-06`；股票股息登记和关联净减持日须在 2015-09-09 至 2026-10-06 的核验范围内。越界明确失败，不以旧制度推断未来税率。账户无股息税事项的普通成交不受此税务日期检查限制。

## 输入与时间

行动事实保留公告、登记、除权、现金到账、股份入账、股份上市日期。股份入账与可卖日期分开；不从除权日猜入账。每股现金及送转应税金额支持六位小数，到账金额及应纳税额按账户／事件聚合后按分半入。

登记日收盘确定本账户权益；除权日产生股息应收与待入账股份，进入权益估值但不能提前当作现金或可卖量。现金到账转入现金。股份入账进入持仓批次，在显式上市日后可卖；其税务取得日期为入账日。

当前模型接受可得到整数股份的权益分配；需要跨账户零碎股排序的情形明确失败，不能向下取整并声称为真实分配。由分配得到的整数零股可以按市场规则一次清仓。未实现的配股、合并或退市行动影响持仓、登记权益、未到账权益或活动委托时失败。

## 双批次与税款

交易批次管理取得成本和可卖日期；税务批次按每日日终已入账股份的净变化独立维护。送转入账与卖出同日发生时，不能直接把实际卖出量作为税务减持量。登记时把本次每股应税收入附到税务批次，后续净减持按 FIFO 和实际持有期形成税款。

日终计提已确定税款，下一输入交易日开盘扣收；这是按交易日结算的时序约定，不宣称还原券商盘中扣款时间。资金不足时保留税款应付并限制可买资金；不让现金变负、不忽略税负、不反向取消已经发生的成交。尚未出售股份的税负仍有条件，结果保留税务批次，不假定样本结束强平。

每日权益为现金 + 股息应收 + 已入账及待入账股份的原始收盘价估值 − 已计提未付税款。样本结束不提前支付未来分红，也不解锁尚未上市股份。`result.entitlements`、`corporate_events`、`tax_lots`、`taxes` 和 `tax_payments` 分别提供登记权益、状态变化、剩余税务批次、计提和实际扣收；金额字段后缀 `_units` 表示万分之一元，税务批次的每股收入 `_micros` 表示百万分之一元。

完整可运行调用见 [分红送转示例](https://github.com/DorisLab/DoriBT/blob/main/examples/dividends.py)。策略只需表达下单意图，权益处理不由策略回调手工补账。

## 验收

独立核对登记／除权／到账分离、到账前卖出、入账前股份估值、上市日解锁、同日送转抵消净减持、跨持有期 FIFO、自然月／年边界、应税红股与免税转增、ETF 分配、欠税后卖出回补，以及未知行动与零碎分配失败。行为需在 Python 和 Numba 两种执行路径通过；Python 生命周期不因启用 Numba 而换另一套税务实现。

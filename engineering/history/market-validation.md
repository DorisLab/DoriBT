# 市场案例验收记录

本记录描述已执行的历史模拟核对，不表示策略推荐、未来收益或真实可成交保证。公开仓库不附未授权原始行情。数据哈希用于识别本轮输入，不能取代数据授权、供应商质量和市场事实核验。

## 2020–2025 创业板 ETF 案例

2026-10-06 使用本地已授权的 `159915.SZ` 日线快照完成验证，区间为 **2020-01-02 至 2025-12-31，共 1455 个交易日**。输入为未复权 OHLC、成交量、停牌状态、独立交易日历和明确价格边界。来自 2026-10-05 导出的静态快照，并非重新联网取得的最新行情。

输入检查包括：原文件 SHA-256 与快照清单一致；区间交易日与独立日历完全相符；无重复行；2021-02-08 为停牌行，独立每日成交存在性检查的唯一缺失日与其对应；分红送转事件表在该区间为空，原始价与研究复权价在快照中一致。供给侧采用旧的已发布文件契约，未纳入新的全局数据治理检查，不能扩大为全部数据质量认证。

CSV 中小于 `1e-9` 元的二进制浮点表示误差显式规范到 ETF 的 `0.001` 元 tick，最大改动为 `5e-16` 元；其余不在 tick 的输入会失败。每日价格边界根据原始前收盘参考价按 tick 半入计算：2020-08-24 以前为 10%，之后为 20%，该证券列于[深交所公布的 ETF 涨跌幅比例调整名单](https://docs.static.szse.cn/www/aboutus/trends/conference/W020200821767425488573.pdf)。本次使用计算边界，未取得逐日官方涨跌停文件来做第二来源交叉核验。

| 验证假设 | 取值 |
| --- | --- |
| 初始现金 | 100,000 元，无外部入出金 |
| 仓位 | 收盘目标 95%，相同权重不每日重算股数 |
| 决策与执行 | 当日收盘决定固定股数，下一输入交易日开盘执行 |
| 费用 | 佣金 0.03%，每次成交最低 5 元；额外印花税／过户费为 0 |
| 滑点 | 每次成交不利方向 1 tick，即 0.001 元 |
| 买入持有 | 首次输入收盘产生意图，第二个交易日开盘首次尝试 |
| 均线 | 20／60 个收盘价，完整 60 个观察值后才决策，不使用 2019 年预热数据 |
| 样本结束 | 保留未平仓持仓，不强制卖出 |

| 策略 | 末日权益（元） | 累计收益 | 最大回撤 | 成交数 | 佣金合计（元） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 买入持有 | 176,313.68 | 76.31368% | 55.12934% | 1 | 28.52 |
| 20／60 均线 | 121,588.53 | 21.58853% | 46.57572% | 25 | 840.97 |

这些数字用于固定案例的回归核对。两个策略均未在该输入中产生受阻委托，因此真实案例本身不验证全部受阻分支；停牌、涨跌停、资金不足、部分成交和重试另由公开人工样例及独立账本测试覆盖。

Python、Numba 两个后端分别与一个不导入 DoriBT 内核／费用／定量函数的 Decimal 参考账本比较：**每日现金、权益和持仓，逐笔成交数量／价格／佣金，以及受阻日期和原因全部精确相同**。均线同时通过收盘回调和预计算目标两种入口运行，完整账户与订单摘要相同。参考账本使用相同的已确定收盘权重；它独立验证执行和账户，不宣称独立证明策略因子的经济有效性。

与此前任何开盘预算型原型比较时，必须重新统一首日、预热、委托定量及期末政策。该记录只对应正式的固定股数模型，不能把原型收益或速度直接当成同一模型的结果。

## 可重复执行的检查工具

源码仓库中的 [market_case.py](../../scripts/market_case.py) 接受标准行情 CSV、带 `session` 列的独立日历 CSV、显式 ETF 市场分类和来源描述。用户须确认区间没有公司行动。它执行两种策略，逐项对账，再以不替换已有文件的方式保存报告；报告包含输入／结果摘要和本次运行假设。检查不用 Python `assert` 控制，即使用 `python -O` 也不能静默移除验证。

```sh
uv run python scripts/market_case.py --market market.csv --calendar calendar.csv \
  --profile szse_equity_etf --source "说明自备数据来源及边界计算方式" \
  --no-corporate-actions --backend python --output verified-python.json
uv run --extra numba python scripts/market_case.py --market market.csv --calendar calendar.csv \
  --profile szse_equity_etf --source "说明自备数据来源及边界计算方式" \
  --no-corporate-actions --backend numba --output verified-numba.json
```

以上换行为 POSIX shell 写法；PowerShell 可写成单行。工具范围是单个普通 T+1 境内股票 ETF，100 股申报单位、单笔 100 万份上限及本案例费用模型。它不是所有证券的通用验证器；公司行动、股票历史费用和多资产共享账户由各自的独立账本与来源案例验证。工具自身也有故意破坏结果、日历缺行、既有报告保护、价格跳空和资金耗尽的反例测试。

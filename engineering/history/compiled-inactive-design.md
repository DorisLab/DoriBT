# 非活动证券编译路径设计

类型：设计与需求响应。日期：2026-10-13。目标版本：0.6.2。

上游输入为 ag-research 的 `doribt-compiled-path-requirements.md`。接受 P0 的合法历史面板、
完整账本、错误时点和公开路径审计要求，并把 P1 的 1／5 分钟一起实现。公司行动、自定义目标和
任意 Python 回调继续兼容执行；不改成交预算、证券分类或研究侧的容量映射。

## 不变量与实现

原有 `market` 数组同时服务申报和撮合，非活动行保持无申报规则。另建只读 `sizing_rules`
五列数组：规则存在、买入最小量、买入步长、卖出步长、卖出最小量。它只服务权重定量，
解析当日显式规则，不前填未来规则。准备阶段的合法缺口不触发业务错误。

准备过程流式读取基础价格列，并把已经验证的 RulePeriod 按有效日期批量写入数组；
不再对每根 bar 重复查询相同规则和多次切片赋值。完整分钟网格保证日期区间的映射，
规则缺口保持为零。RuleBook 子类保留逐日 at 查询，避免绕过用户重写的行为。
独立检查区间缺口、规则变更、非活动但有显式规则，以及子类与批量路径的数值等价。

零权重直接定量为零，但之后的意图、持仓、旧子单、冻结和估值生命周期照常执行。非零权重
在真正定量时先检查规则、再检查价格及溢出；编译错误携带 bar、模式、证券列和错误码，由
Python 边界恢复原异常类型、消息和 close 因果链。close 对所有证券定量完成后才替换任何意图。

公共来源新增 `execution_plan`，由实际选择的运行器产生，不重新猜测输入资格。原
`execution_path` 含义不变。禁用 JIT 时使用兼容分段并明确实际 Python 后端。非法未来目标
不预扫描，避免它抢先替代更早的估值错误。本版没有部分区间编译，因此无需虚构区间计数。

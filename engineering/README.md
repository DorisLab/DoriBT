# 工程记录

面向使用者的入口是[使用手册](https://dorislab.github.io/DoriBT/)和[可运行示例](../docs/examples.md)。本目录保留维护者需要的验证证据，不进入文档站。

- [发布维护](publishing.md)：PyPI、GitHub Release、Pages 和 CI 触发规则。
- [质量门禁](../docs/quality.md)：本地与里程碑检查。
- [推进与验收记录](release-progress.md)：按时间追加的实现范围、检查结果和未验证边界。
- `history/`：阶段方案、市场与性能验证、早期发行记录。内容以当时的提交和环境为准，不能替代当前接口文档。
